## 几个买了才会注意到的限制

只支持 macOS，这是最硬的一条。官网提供的构建就是 Mac 的，Windows 和 Linux 用户直接排除，没有绕过的办法。

Standard 只授权 1 台 Mac。换电脑要转移授权，具体能不能转、怎么转，以许可证条款为准，买之前最好确认清楚。

更新只含 1 年。之后想继续拿新版本，得手动续订，不会自动扣费，但也不是免费。官网的续订页面可以在更新日期后六个月内操作，也可以在应用弹出的提醒里点进去，续订一次加一年，密钥和原始购买日期不变。

Team 要每 7 天联网验证。出差、内网隔离环境或者长期离线的机器要留意这一点，Standard 没有这个要求。

免费版的限制会很快撞墙。Packet Diff 只有 2 项，结构化过滤只有 1 行，拿来当正式工具用，几天就会想升级。

值得肯定的地方也很具体。协议解析直接用了 Wireshark 的解析器，字段高亮、十六进制对照这些细节跟 Wireshark 一致，不用重新学一套。Follow TCP Stream 做成了独立窗口，双向流量可以合并看，也能单独看某一个方向，比在原版里翻找省事。命令行能起停抓包、按协议或端口过滤、导出 JSON，写脚本的人会喜欢。

源码以 GPL-2.0-or-later 发布，做安全的人可以自己审计它怎么处理流量。付费买的是官方构建里的 PRO 功能、设备席位、一年更新和邮件支持，不改变 GPL 给你的权利。

官网 testimonials 页收集的反馈集中在两点，一是终于有人做了个简化的 Wireshark，二是开源许可让人放心。这些是厂商自选的评价，不是独立第三方测评，参考价值有限。目前没有找到可信的独立评分平台数据，所以关于稳定性、崩溃率这类问题，我没法给结论。
